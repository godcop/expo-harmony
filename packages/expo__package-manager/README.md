# @expo-harmony/expo__package-manager

为 HarmonyOS 上的 React Native / Expo 项目提供 `@expo/package-manager` 的兼容入口。实际 JavaScript 实现由官方包提供。

## 安装

```bash
npm install @expo-harmony/expo__package-manager @expo/package-manager@1.10.5
```
