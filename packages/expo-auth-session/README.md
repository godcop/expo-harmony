# @expo-harmony/expo-auth-session

为 HarmonyOS 上的 React Native / Expo 项目提供 `expo-auth-session` 的兼容入口。实际 JavaScript 实现由官方包提供。

## 安装

```bash
npm install @expo-harmony/expo-auth-session expo-auth-session@55.0.16
```
