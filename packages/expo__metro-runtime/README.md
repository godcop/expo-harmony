# @expo-harmony/expo__metro-runtime

为 HarmonyOS 上的 React Native / Expo 项目提供 `@expo/metro-runtime` 的兼容入口。实际 JavaScript 实现由官方包提供。

## 安装

```bash
npm install @expo-harmony/expo__metro-runtime @expo/metro-runtime@55.0.11
```
