# @expo-harmony/expo__local-build-cache-provider

为 HarmonyOS 上的 React Native / Expo 项目提供 `@expo/local-build-cache-provider` 的兼容入口。实际 JavaScript 实现由官方包提供。

## 安装

```bash
npm install @expo-harmony/expo__local-build-cache-provider @expo/local-build-cache-provider@55.0.16
```
