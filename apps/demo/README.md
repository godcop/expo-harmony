# demo

这是 Expo Harmony 的示例应用，接入了目前仓库中的各个已适配的模块。

HarmonyOS demo 直接加载自身应用，不依赖 Dev Client 或 Dev Launcher。开发菜单直接使用 `expo-dev-menu`，LogBox、网络检查和 Reload 仍然保留。
